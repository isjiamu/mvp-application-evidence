## Method-to-resource translation / 方法转化为资源

- **Inputs / 输入：** Explicit business context, audience, theme, findings and constraints.
- **Workflow / 流程：** Information checks, research, analysis and structured drafting.
- **Output specification / 输出要求：** Defined document sections and cross-document consistency.
- **Guardrails / 边界：** Missing information and assumptions identified; sources recorded; experts, fees or outcomes not fabricated.
- **References and scripts / 参考与脚本：** Methods/templates separated from task instructions; document-generation support retained.

The program-design package supports an evidence-based mode using supplied findings and a preliminary mode using project background. Its preliminary mode marks assumptions for later review. The needs-assessment package requires strategic, task and individual perspectives and records sources for external research.

学习方案包区分基于真实调研发现的模式和基于项目背景的初稿模式，初稿中的假设需标注待补；需求调研包要求三层面分析，并为外部调研记录来源。

These resources demonstrate how professional methods, prompts, reference material and scripts can be organized for repeatable work. Static archive checks establish file integrity and structure; they do not establish runtime success, platform compatibility, learner adoption or improved teaching outcomes.

资源体现专业方法、指令、参考与脚本的组合方式。静态检查只确认文件完整性与结构，不证明实际运行、平台兼容、学员采用或教学成效。

The original packages and their reference content remain local. No internal institutional templates, client cases or generated client documents are publicly uploaded here. The post's slide 45 preview documents the instructional Skill structure.
